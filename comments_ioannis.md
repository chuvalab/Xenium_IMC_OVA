Generic comemnts are provided here:

* Jupyter notebooks are meant to save the output. It is also much easier to follow them if the output (plots) are there
* Did you use conda environemts? Good to save the version of the packages used. This is important for reproducibility
* Make your markdown cells more readable and neat by capitalizing and pay attantion to the grammar. For example `1. load package -> Load packages`
* Add some the resources you used at the top of the script. For example the tutorials you followed or the documantation of a package
* You can combine python and R in a single notebook, see https://anderfernandez.com/en/blog/how-to-program-with-python-and-r-in-the-same-jupyter-notebook/. Much more convenient than splitting them in two scripts
* You can add the figure number as a comment or at least provide a more detailed description of the plot you are making. This makes navigating into the code easier
* Think if you can break the notebook into smaller ones, based on the plot or maybe the type of analysis. One big file with hudrends of lines and dozen of plots is hard to follow
* Keep the code tidy and readable: store the code in blocks according to function, do not leave unessecary blanc lines. If possible, follow a PEP 8 (https://peps.python.org/pep-0008/)
* Avoid spaces in file names, it makes it harder to work with them in command line
